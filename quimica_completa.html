КИСЛОТЫ

Сложные вещества, состоящие из атомов водорода и кислотных остатков. При диссоциации образуют катионы \(H^+\) и анион кислотного остатка.

01 🌡️ Физические свойства
  • Жидкие: \(HNO_3,\ H_2SO_4\)
  • Твёрдые: \(H_3PO_4,\ H_3BO_3\)
  • Растворы газов: \(HCl,\ H_2S\)
⚠️ Нестабильные кислоты существуют только в растворах и разлагаются:
\(H_2SO_3 \rightarrow H_2O + SO_2\)
\(2HNO_2 \rightarrow H_2O + NO + NO_2\)
02 👑 Главные названия
  • \(HCl\) — Хлороводородная (соляная)
  • \(H_2S\) — Сероводородная
  • \(HBr\) — Бромоводородная
  • \(HNO_3\) — Азотная
  • \(H_2SO_4\) — Серная
  • \(H_3PO_4\) — Фосфорная
  • \(H_2CO_3\) — Угольная
  • \(H_2SiO_3\) — Кремниевая
03 🚦 Классификация
  • По наличию кислорода: Кислородные (\(H_2SO_4\)) и Бескислородные (\(HCl\))
  • По основности: Одноосновные (\(HNO_3\)) и Многоосновные (\(H_3PO_4\))
  • По растворимости: Растворимые (\(HCl\)) и Нерастворимые (\(H_2SiO_3\))
  • По летучести: Летучие (\(H_2S\)) и Нелетучие (\(H_2SO_4\))
  • По силе: Сильные (\(HNO_3\)) и Слабые (\(H_2SO_3\))

05 🥊 Химические свойства
  • 01+ Основание: → Соль + Вода
    \(H_2SO_4 + 2NaOH = Na_2SO_4 + 2H_2O\)
  • 02+ Оксид металла: → Соль + Вода
    \(2HCl + CuO = CuCl_2 + H_2O\)
  • 03+ Металл: → Водород + Соль
    \(2HCl + Zn = ZnCl_2 + H_2\uparrow\)
    Металл должен стоять ДО водорода в ряду напряжений. Железо окисляется до \(Fe^{2+}\).
  • 04+ Соль: → Новая кислота + Новая соль (газ, осадок или вода)
    \(BaCl_2 + H_2SO_4 = BaSO_4\downarrow + 2HCl\)
06 🏭 Способы получения
  • Кислотный оксид + Вода: \(SO_3 + H_2O \rightarrow H_2SO_4\)
  • Вытеснение летучей кислоты: \(NaCl + H_2SO_4 \rightarrow HCl + Na_2SO_4\)
  • Гидролиз галогенидов: \(PCl_5 + H_2O \rightarrow H_3PO_4 + HCl\)
  • Из простых веществ: \(H_2 + Cl_2 \rightarrow 2HCl\)
07 🌟 Амфотерные гидроксиды

Проявляют и кислотные, и основные свойства в зависимости от условий.

  • Гидроксид алюминия как основание: \(Al(OH)_3\)
  • Гидроксид алюминия как кислота: \(H_3AlO_3\)
  • + Кислота: \(Zn(OH)_2 + 3HCl = ZnCl_2 + 3H_2O\)
  • + Основание: \(Zn(OH)_2 + 2NaOH \rightarrow Na_2[Zn(OH)_4]\)
⚠️ При избытке щёлочи (\(NaOH\) изб.) осадок растворяется и образуется комплексная соль.

СОЛИ

СОЛЬ = Ион металла + Кислотный остаток. Образуются при замещении атомов водорода в кислоте ионами металлов.

01 🧬 Что такое соли?
  • В основном — белые кристаллические вещества.
  • Соли железа (Fe) — желто-коричневые.
  • Соли меди (Cu) — зеленовато-голубые.
02 🏷️ Номенклатура

Формула: Название кислотного остатка + Название металла (в род. падеже)

  • 🚫 Бескислородные: суффикс -ИД
    • \(NaCl\) — хлорид натрия
    • \(Al_2S_3\) — сульфид алюминия
  • 🎈 Кислородсодержащие:
    • Высшая степень окисления: суффикс -АТ → \(Na_2SO_4\) — сульфат натрия
    • Низшая степень окисления: суффикс -ИТ → \(Na_2SO_3\) — сульфит натрия
03 🚦 Классификация

А) По растворимости

  • 💧 Растворимые: \(NaCl\)
  • 🐢 Малорастворимые: \(CaSO_4\)
  • 🧱 Нерастворимые: \(CaCO_3\) (осадок)

Б) По типам

  • 🟢 Нормальные: все H заменены на металл — \(NaCl,\ Na_2SO_4\)
  • 🍋 Кислые: H замещён частично — \(NaHSO_4\)
  • 🧼 Основные: OH замещён частично — \(MgOHCl\)
  • 👯 Двойные: два разных катиона металла — \(KAl(SO_4)_2\)
  • 🧩 Комплексные: сложный ион в скобках — \(Na_2[Zn(OH)_4]\)
04 🥊 Химические свойства
  • 01⚔️ + Металл: Вытеснение менее активного
    \(Fe + CuSO_4 = FeSO_4 + Cu\)
    ⚠️ Исключение: Li, Na, K, Ca, Ba — реагируют с водой!
  • 02🍋 + Кислота: → газ или осадок
    \(Na_2CO_3 + 2HCl = 2NaCl + CO_2 + H_2O\)
  • 03🧼 + Щёлочь: → нерастворимое основание
    \(AlCl_3 + 3KOH = Al(OH)_3\downarrow + 3KCl\)
  • 04🧂 + Соль: → нерастворимая соль
    \(Na_2SO_4 + BaCl_2 = BaSO_4\downarrow + 2NaCl\)
  • 05🔥 Разложение при нагревании:
    \(CaCO_3 = CaO + CO_2\)
05 🏭 Способы получения
  • Металл + Неметалл: \(2Fe + 3Cl_2 = 2FeCl_3\)
  • Кислотный оксид + Основный оксид: \(CaO + CO_2 = CaCO_3\)
  • Основание + Кислота: \(NaOH + HCl = NaCl + H_2O\)
  • Соль + Соль → новая нерастворимая соль
  • Соль + Более активный металл
  • Кислота + Металл (до \(H_2\) в ряду напряжений)
06 🧬 Генетическая связь

Связь между классами неорганических соединений — как из одного получить другое.

🛡️ Ряд металла

Металл → Основный оксид → Основание → Соль
\(Ca \rightarrow CaO \rightarrow Ca(OH)_2 \rightarrow CaCO_3\)

💨 Ряд неметалла

Неметалл → Кислотный оксид → Кислота → Соль
\(C \rightarrow CO_2 \rightarrow H_2CO_3 \rightarrow CaCO_3\)

📝 Решённые задания · Глава 3

УПРАЖНЕНИЯ

Генетические цепочки превращений с уравнениями и объяснениями.

EX1 Ряд углерода (Serie genética del carbono)
\(C\) → \(CO_2\) → \(H_2CO_3\) → \(CaCO_3\)
01 \(C \rightarrow CO_2\) — Неметалл → Кислотный оксид
\(C + O_2 \rightarrow CO_2\)

Explicación:

Reacción de oxidación (combustión) del carbono.

02 \(CO_2 \rightarrow H_2CO_3\) — Кислотный оксид → Кислота
\(CO_2 + H_2O \rightarrow H_2CO_3\)

Explicación:

El óxido ácido interactúa con agua para formar su ácido correspondiente (ácido carbónico).

03 \(H_2CO_3 \rightarrow CaCO_3\) — Кислота → Соль
\(H_2CO_3 + Ca(OH)_2 \rightarrow CaCO_3\downarrow + 2H_2O\)

Explicación:

Reacción de neutralización. El ácido reacciona con hidróxido de calcio y forma carbonato de calcio (precipitado) y agua.

También válido: \(H_2CO_3 + CaO \rightarrow CaCO_3\downarrow + H_2O\)
EX2 Ряд алюминия — Амфотерный (Serie genética del aluminio)
\(Al\) → \(Al_2O_3\) → \(AlCl_3\) → \(Al(OH)_3\) → \(Na[Al(OH)_4]\)
01 \(Al \rightarrow Al_2O_3\) — Металл → Амфотерный оксид
\(4Al + 3O_2 \rightarrow 2Al_2O_3\)

Explicación:

Oxidación del metal para formar óxido de aluminio.

02 \(Al_2O_3 \rightarrow AlCl_3\) — Амфотерный оксид → Соль
\(Al_2O_3 + 6HCl \rightarrow 2AlCl_3 + 3H_2O\)

Explicación:

El óxido anfótero actúa como óxido básico al reaccionar con ácido clorhídrico para formar sal y agua.

03 \(AlCl_3 \rightarrow Al(OH)_3\) — Соль → Амфотерный гидроксид
\(AlCl_3 + 3NaOH \rightarrow Al(OH)_3\downarrow + 3NaCl\)

Explicación:

La sal reacciona con cantidad exacta de álcali formando el hidróxido insoluble como precipitado.

04 \(Al(OH)_3 \rightarrow Na[Al(OH)_4]\) — Амфотерный гидроксид → Комплексная соль
\(Al(OH)_3 + NaOH \rightarrow Na[Al(OH)_4]\)

Explicación:

Con exceso de álcali, el precipitado anfótero actúa como ácido y se disuelve formando tetrahidroxoaluminato de sodio (sal compleja).
